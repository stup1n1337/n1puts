Локальная реконструкция по сохранённому HTML.

Откройте index.html в браузере или разместите все файлы в одной папке на веб-сервере.

Важно: исходный HTML содержит ссылки на blob:-скрипты из браузерной сессии, а HAR содержит только один ответ 304 без отдельных JS/CSS/изображений. Поэтому буквально восстановить исходную клиентскую логику по этим двум файлам нельзя; внешний вид взят из сохранённого HTML, интерактивность частично воспроизведена отдельно в script.js.
