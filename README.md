## Важно: общий счётчик
Для единого счётчика нужен серверный API. В архиве есть `api/click.php`, который хранит число в `api/data/count.txt` и использует файловую блокировку, чтобы параллельные клики не перетирали друг друга.

Это требует работающего PHP на веб-сервере и права PHP-процесса создавать/записывать файлы в `api/data/`. Если сайт обслуживается только как статические файлы, API нужно подключить к серверному PHP либо заменить на базу данных/внешний backend. Проверка: открой `https://n1puts.ru/api/click.php` — должен вернуться JSON вида `{"count":0}`.

## Мемы
Картинки клади в `img/memes/`, а имена добавляй в `img/memes/list.json`, например:
```json
[
  "meme-01.webp",
  "cat.png",
  "random.gif"
]
```

## Деплой
Скопируй содержимое архива в корень репозитория, сохранив папки `services/`, `img/` и `api/`. Затем:
```bash
git add -A
git status
git commit -m "Redesign homepage and add global clicker"
git push origin main
deploy-n1puts
```
