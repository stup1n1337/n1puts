# n1puts.ru — версия 7

## Визуальные изменения
- Солнце на главной полностью видно и находится над логотипом `n1puts.ru`.
- Мемы и общий кликер расположены ниже логотипа.
- В шапке только навигация; внизу оставлен только Telegram, менее акцентный.
- В счётчике сверху теперь только зелёный индикатор и надпись `LIVE`.
- Заголовок «СЕРВИСЫ» получил такую же белую заливку, чёрную обводку и цветные тени, как главный логотип.
- Иконки сервисов получили светлую подложку и рамку, чтобы не теряться на ярких карточках.

## Общий счётчик — важно
Фронтенд обращается к `/api/click.php`. Это должен быть исполняемый PHP-скрипт, а не файл, который nginx отдаёт как статический текст. Если PHP на хостинге не настроен, общий счётчик не заработает: браузер не может безопасно записывать единый счётчик только статическими HTML/CSS/JS.

Проверь `https://n1puts.ru/api/click.php`. Ожидается JSON вида `{"count":0}`. Если видишь исходный PHP-код, 404 или 502 — требуется настроить PHP-FPM и nginx для маршрута `/api/`, либо выбрать другой backend. Также PHP-процессу нужны права на создание/запись в `api/data/`.

**Не заменяй общий счётчик на `localStorage`:** тогда число будет разным у каждого посетителя, что не соответствует задаче.

## Мемы
Картинки клади в `img/memes/`, а имена добавляй в `img/memes/list.json`, например:
```json
[
  "meme-01.webp",
  "cat.png",
  "random.gif"
]
```

## Деплой
Скопируй содержимое архива в корень репозитория, сохранив папки `services/`, `img/` и `api/`.
```bash
git add -A
git status
git commit -m "Polish homepage and service branding"
git push origin main
deploy-n1puts
```
