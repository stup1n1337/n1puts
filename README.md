# n1puts.ru — обновлённая версия

## Установка
1. Сделай резервную копию текущего сайта.
2. Загрузи содержимое архива в корень сайта, сохранив структуру папок.
3. Главная страница — `index.html`; страница сервисов — `services/index.html`, URL `/services/`.
4. Ссылки сервисов и соцсетей сохранены из предыдущего макета; проверь их перед публикацией.

## Свои картинки

### Случайные картинки
Положи изображения в `img/memes/` и перечисли имена файлов в `img/memes/list.json`. Пример:
```json
[
  "my-meme-01.png",
  "meme-02.webp",
  "random.gif"
]
```
Поддерживаются JPG, PNG, WebP, GIF и AVIF. Файлы должны реально существовать в этой папке. На кнопке «ЕЩЁ ОДНУ» и при клике на изображение выбирается случайная картинка без подписи.

### Декор на фоне
Положи PNG/WebP/GIF с прозрачностью в `img/stickers/` и укажи имена в `img/stickers/list.json`, например:
```json
[
  "cat.png",
  "logo.webp",
  "sticker.gif"
]
```
Стикеры автоматически раскидываются по экрану и слегка двигаются. Удали `list.json` или оставь пустой массив `[]`, если фон пока нужен чистый.

## Кликер
Звания: USER → SUDO USER → SYSADMIN → ROOT → DEVOPS → KERNEL PANIC. Пороги кликов настраиваются в `script.js` в массиве `ranks`.

## Примечания
- Редактор `EDIT.EXE` — компактное плавающее окошко. Изменения цвета/наклона действуют в текущем открытом окне и не сохраняются после перезагрузки.
- Внешний вид использует Google Fonts; при недоступности сети будут применены запасные шрифты.
- Проверьте, что веб-сервер отдаёт `services/index.html` для URL `/services/`.
