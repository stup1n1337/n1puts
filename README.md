# n1puts.ru — версия 3

## Структура
- `index.html` — главная: логотип, случайный мем (hui.png), ссылки на соцсети и неоновый Hotline-inspired фон.
- `services/index.html` — отдельная страница сервисов.
- `huynya/index.html` — вакханалия эффектов и кликер; цитата удалена.
- `style.css` — стили всех страниц.
- `script.js` — случайная смена мемов на главной.
- `huynya.js` — интерактивности страницы «хуйня».
- `img/memes/` — твои изображения для главной.
- `img/icons/` — иконки карточек сервисов.

## Как добавить мемы
1. Загрузи картинки в `img/memes/`, например `meme-01.webp`, `cat.png`, `what.gif`.
2. В `img/memes/list.json` укажи имена файлов:
   ```json
   [
     "meme-01.webp",
     "cat.png",
     "what.gif"
   ]
   ```
3. Имена должны точно совпадать с файлами. Картинки показываются без подписей; кнопка «ЕЩЁ ХУЙНИ» выбирает случайную.

## Иконки сервисов
Страница использует локальные SVG в `img/icons/`: `kuma.svg`, `grafana.svg`, `immich.svg`, `seafile.svg`, `openwebui.svg`, `proxmox.svg`. Они включены в архив. Не удаляй и не переименовывай их, если не меняешь пути в `services/index.html`.

## Размещение
Загрузи содержимое архива в корень сайта, сохранив структуру папок. Пути рассчитаны на сайт в корне домена: `/style.css`, `/img/...`, `/services/`, `/huynya/`. Если перед публикацией используешь Git, проверь `git status` и `git log -1 --stat`, чтобы убедиться, что новые `index.html`, `style.css`, `script.js`, `huynya/` и `services/` действительно попали в коммит.

Бегущая строка `n1puts.ru` расположена внизу каждой страницы. Ссылки на сервисы и соцсети заданы в HTML — проверь их перед публикацией.
